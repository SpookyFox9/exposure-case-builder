# Insider Case Builder

Baselines each user's activity against their peers, flags deviations with rule-based detectors, and assembles a case file with a timeline and the source records behind every finding. Claude writes the narrative; a human analyst records the disposition.

> Status: work in progress. Sections marked _TODO_ are filled in as the build lands.

## Purpose

Output is evidence and facts, not verdicts. The tool makes no HR or disciplinary recommendations. Every finding carries the source record IDs that triggered it. Detectors are deterministic rules; there is no ML.

## Prerequisites

- Python >= 3.10 and [`uv`](https://docs.astral.sh/uv/)
- Claude Code (for the MCP server and the `/insider-case` skill)

## How to run

```bash
uv sync
uv run pytest
uv run python scripts/make_synthetic.py data/synthetic 42   # seeded synthetic dataset
```

## Data flows

No outbound network calls. The only planned exception is `scripts/download_cert.py`, which fetches the public CERT dataset when you run it. The only write is `record_disposition`, a local append-only JSONL log that requires `confirm=true`. No tool changes any external system.
